# Инструкция по настройке прозрачного Wi-Fi моста (L2 Bridge)

**Оборудование:**
* **Главный роутер:** MikroTik hAP ax2 (IP: `192.168.1.1`)
* **Роутер-приемник:** MikroTik hAP lite (IP: `192.168.1.254`)

---

## 1. Подготовка и сброс
Чтобы настройки не конфликтовали с заводскими, hAP lite должен быть чистым.

* **Сброс:** Удерживать кнопку **Reset** при подаче питания 5-7 секунд до мигания индикатора **ACT**.
* **Доступ:** WinBox по MAC-адресу или IP `192.168.88.1`.

## 2. Настройка безопасности (Security Profile)
Прежде чем подключаться к главной сети, нужно создать профиль с паролем.

**Путь:** `Wireless` -> `Security Profiles` -> `+`

* **Name:** `main_pass`
* **Mode:** `dynamic keys`
* **Authentication:** Только **WPA2 PSK** (для совместимости со старым hAP lite).
* **WPA2 Pre-Shared Key:** Ваш пароль от основного Wi-Fi.

## 3. Настройка приема интернета (wlan1)
Ключевой момент — использование режима «псевдомоста» для совместимости разных поколений Wi-Fi.

**Путь:** `Wireless` -> `Interfaces` -> `wlan1`

* **Mode:** `station-pseudobridge` (обязательно для связи ax2 -> lite).
* **Band:** `2GHz-b/g/n`
* **SSID:** Имя вашей основной сети 2.4 ГГц.
* **Security Profile:** `main_pass`

**Результат:** После нажатия **OK** в списке интерфейсов должна появиться буква **R** (Running).

## 4. Настройка локальной сети (IP и DHCP)
Превращаем роутер из «главного» в «подчиненный».

* **Удаление DHCP:** `IP` -> `DHCP Server` -> Удалить все записи.
* **Удаление Pool:** `IP` -> `Pool` -> Удалить все записи.
* **Смена IP:** `IP` -> `Addresses` -> Изменить `192.168.88.1` на `192.168.1.254/24` (Interface: `bridge`).
* **Очистка Firewall:** `IP` -> `Firewall` -> Удалить все правила во вкладках **Filter Rules** и **NAT**. Это делает мост «прозрачным».

## 5. Настройка моста (Bridge)
* **STP:** `Bridge` -> Выбрать ваш мост -> Вкладка `STP` -> **Protocol Mode:** `none`. Это предотвращает ложные блокировки порта (особенно важно для iPhone).
* **Порты:** `Bridge` -> `Ports` -> Убедиться, что там добавлены `wlan1` (прием) и `wlan2` (раздача).

## 6. Виртуальная точка доступа в комнате (wlan2)
**Создание:** `Wireless` -> `Interfaces` -> `+` -> `Virtual`

* **Mode:** `ap bridge`
* **SSID:** Новое имя сети для комнаты.
* **Master Interface:** `wlan1`
* **Security Profile:** `main_pass`
